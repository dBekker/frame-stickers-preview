# Фрейм — лендинг UV DTF-наклеек (Vite + React)

Версия 2: строгая B2B-подача для маркетологов, реальные фото и hero-видео.
Прежняя «игривая» версия сохранена в `_v1-playful/`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # предпросмотр сборки
```

## Структура

```
src/
  data.js     # ВЕСЬ контент: тексты, списки фото, шаги, FAQ, формула калькулятора
  App.jsx     # секции страницы
  ui.jsx      # кнопки, LoopVideo, калькулятор, FAQ, иконки
  index.css   # стили и адаптив (токены в .fp{ … })
public/
  video/      # hero-лупы A/B/C/D (v2-ramp): webm + mp4 + постеры; A — ещё и 9:16
  img/        # фото 1600px, pNNN.jpg = «1 (NNN).JPG» из съёмки
```

Где что стоит: видео A — первый экран, C — «Технология», D — плитка в «Материалах», B — «Процесс».
Видео играют только в зоне видимости; при `prefers-reduced-motion` остаётся постер.

## Что осталось подключить

- Форма заявки (`App.jsx`, `<form className="form">`) — сейчас никуда не отправляет.
- `calcPrice()` в `data.js` — ориентировочная формула, заменить на реальную тарификацию.
- Клиенты — текстом; при наличии логотипов заменить список в `.clients`.
- Политика конфиденциальности — ссылка-заглушка.
